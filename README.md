### Current Focus

Building at the intersection of AI governance, cognitive infrastructure, and financial intelligence:

- **[agent-contracts](https://github.com/Skull-boy/agent-contracts)** — Evolving from a workflow governance spec into a self-evolving, domain-independent agent harness. Defines the contract layer MCP and A2A left out: what agents are *allowed* to do. v1.1 introduces a layered architecture (Universal Core → Domain Profiles → Extensions) so the same contract model works across dev, healthcare, finance, and education — not just coding pipelines.

- **[ContextBridge (CVCS)](https://github.com/Skull-boy/agent-contracts)** — A Cognitive Version Control System. Headless, event-driven middleware that acts as a shared memory layer for multi-role AI engineering teams — syncing constraints from non-technical stakeholders (Slack, web UI) directly into developer AI tools (Claude Code, Cursor, Copilot) via MCP, before a single line of code is written.

- **[Finley](https://github.com/Skull-boy/Finley)** — An AI financial co-pilot that lives entirely in Telegram. Pairs Gemini's reasoning with live market data from Finnhub, yfinance, and SEC EDGAR — backed by persistent semantic memory. Drop in a voice note, a PDF, or an earnings chart and Finley researches it, remembers your context, and proactively monitors your portfolio with price alerts and morning briefings. Built on zero paid APIs.

- **Styme / StudyBuddyy.ai** — Founder & Lead Dev. Multi-agent LLM tutoring platform (LangGraph + Gemini/Claude/Groq) serving 500+ campus users, with concurrent inference routing and agentic CoT/ReAct prompting.

- **R&D Intern @ NIT Durgapur** — Applied AI research at the intersection of theoretical algorithms and production agent systems.
